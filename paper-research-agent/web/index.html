서버를 먼저 실행하세요

이 페이지는 화면일 뿐입니다. 논문 검색·검증·저장은 같이 들어 있는 파이썬 서버가 합니다.

압축을 푼 폴더에서 터미널(또는 PowerShell)을 열고:

pip install -r requirements.txt
python server.py

브라우저가 http://127.0.0.1:8765 로 열립니다. 주소창이 파일 …index.html이면 아직 서버를 거치지 않은 상태입니다.

논문 탐색 에이전트 검증된 것만 요약합니다. 검증 못 한 것도 함께 보여줍니다.

설정

한 번 저장하면 config.yaml에 남습니다. API 키는 .env에만 저장되고 브라우저로는 마스킹된 값만 돌아옵니다.

쿼리 생성과 요약에만 씁니다. 검증은 모델과 무관합니다.
litellm 모델 문자열입니다.
이 컴퓨터의 .env 파일에만 저장됩니다.
OpenAlex·Crossref가 요청 한도를 늘려주고, Unpaywall은 이게 없으면 동작하지 않습니다.
검증을 통과한 논문이 이만큼 모이면 멈춥니다.
목표에 못 미치면 쿼리를 새로 만들어 다시 찾습니다.
낮추면 더 많이 통과하고, 잘못 통과할 확률도 올라갑니다.
링크가 아니라 전문 텍스트를 직접 받아옵니다. PDF 다운로드·파싱 단계를 건너뛰어 실패가 크게 줍니다. 무료 발급
엄격은 논문당 3초 이상 더 걸립니다.
노트가 이 폴더 아래 papers/와 sessions/에 쌓입니다.

연구 질문

찾고 싶은 주제를 자연어로 쓰세요. 검색 키워드는 LLM이 영어로 만들어 냅니다.

확실히 관련 있는 논문을 한두 편만 넣어도 결과가 크게 달라집니다. 그 논문의 분야 용어를 검색어에 쓰고, 참고문헌과 피인용 논문까지 따라가기 때문입니다 — 키워드 검색이 못 찾는 논문이 여기서 나옵니다.
